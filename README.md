# ZIoVPO — практика 1 (трей-приложение)

Win32-приложение с иконкой в системном трее, меню и одним экземпляром на пользователя.

## Сборка (CMake)

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

Исполняемый файл: `build\Release\ziovpo-practs.exe`

## Запуск

| Режим | Команда |
|--------|---------|
| Обычный | `ziovpo-practs.exe` |
| Без главного окна | `ziovpo-practs.exe --hidden` |

## Поведение

- ЛКМ по иконке в трее — показать главное окно
- ПКМ — контекстное меню («Открыть», «Выход»)
- Закрытие окна (крестик) — сворачивание в трей, процесс продолжает работу
- Повторный запуск — завершение до добавления иконки в трей (именованный мьютекс)
- После пересоздания панели задач иконка восстанавливается (`TaskbarCreated`)
